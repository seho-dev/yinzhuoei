前阵子刚过完 18 岁生日，一些很久不联系的朋友送上了祝福。简单回忆一下这几年的经历吧。

很多人已经知道我的经历了：高三辍学，学编程，那时不到 17 岁。15 岁左右开始接触互联网灰色产业，跟几个大哥哥一起写脚本赚点收入，满足当时的虚荣心。

转变发生在一次放学回家。我把书房门关上，从书包里掏出书本，电脑打开假装写作业，每天看行业动态、写脚本更新软件。老妈一来就假装写作业。这样下去不是长久之计，有天晚上我跟老妈坦白：我想正规学一下计算机。就这样来到了西安某技校大专。

在那之前，我觉得技术比同龄人超前，有沾沾自喜的自豪感。但现实狠狠打击了我——几乎浪费了一年时间。没有学习路径，很迷茫。18 年停了所有业务线，只剩博客。6 月开始学习前端 + Java，随身带笔记本，去图书馆查资料、看视频、看纯英文官方文档。那段时间提升最大，短短几个月认识了很多好友，有正在学习的，有已经工作的程序员。他们讨论的问题总是我下一个要学的知识点。当时我的技术栈是 Vue 和 Java。

转折来了。班上同学感觉快毕业了（两年制），很多人开始找工作，测试、运维什么的。我也想去，坐井观天想试试水，就投了简历（18 岁，大专）到西安 3 个小厂，只有一个通知面试。

面试跟一个好朋友一起去的。他 21 岁，当过兵，原生 JS 正规学习过。去了一个比较大的小区，里面是个工作室，7 个人左右的小团队。进去之后老板不在，忍了。一个 PHP 开发跟我聊，说他们最近有个 Vue 项目，想找个有经验的带带他们，他们也在学。我懵了，朋友也懵了，这算什么？逗我？然后问我：会 PHP 吗？我说学过两天，如果需要的话可以一周上手。她说：你只会有 Java？我说是的。又问：nuxt 框架会吗？听起来不太专业。我说会，昨天刚看了文档。她想了想说：今天早上来了两个前端的在等通知，简历先放这里，有实习机会再联系。（99% 凉了）

这次面试尴尬的原因：准备太仓促、当时才 17 岁不能录用、简历太草率、项目经验没写全。但这次面试对我帮助很大，让我找到了方向。出了那扇门，自信伴随着复仇之火又燃起来了。接下来的两个月学了很多东西，也安排了明年和过年的计划。

这两天解决了困扰两天的 Java bug，老师也束手无策，我已经在崩溃边缘。写这篇文章是为了警醒自己：不能放弃任何一件事。年龄小可以用技术征服，但心智小，就真的结束了。
