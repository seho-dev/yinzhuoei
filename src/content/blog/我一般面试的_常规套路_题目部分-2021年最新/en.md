## JS

- The event loop; synchronous and asynchronous execution; blocking and non-blocking operations
- Closures
- Scope chains and prototype chains, prototypes and inheritance...
- The call stack
- Reviewing functions
- Promise【new】
- Proxy【new】
- Data types / reference types
- Deep and shallow copies, and the pros and cons of different implementations
- Currying
- Modules

## Vue

- The core ideas behind Vue2 and Vue3: compare their similarities and differences
- How scoped CSS works
- The virtual DOM (also asked in React interviews)
- MVVM (I wasn't going to include this, but it really does come up in interviews)
- What does Vue3 bring? What are its new features?
- Discuss Vite: why is it so fast, and what problems does it primarily solve?

## React

- How do you run a callback after a useState update?
- Class components vs. function components
- Are state updates synchronous or asynchronous?
- What do hooks bring to React?

## Webpack/Vite/SnowPack/Babel

- Briefly describe webpack's build process
- What are some common webpack optimization techniques?
- Which commonly used loaders do you know? What do css-loader and style-loader do?
- Which commonly used plugins do you know?
- What's the difference between loaders and plugins?
- Briefly explain source maps
- How can you speed up webpack builds?
- How does webpack implement hot module replacement?
- How does webpack bundle modules?
- How does webpack watch files for changes?
- What is code splitting in webpack fundamentally, and why is it useful?
- Briefly explain how Babel works
- Why is Vite so fast during development?
- Why can Vite (or esbuild) compile TypeScript so quickly?

## CSS

- The Web Components specifications (just explain the three core concepts)
- How can you make an element disappear from a page?
- Reflow and repaint: how do you write components to reduce their overhead? (Mentioning the contain property is enough.) Does transform trigger reflow?
- How do you change styles inside a component? (Deep selectors)
- How can CSS read attributes from an HTML element?
- Have you used calc?
- Briefly explain BFCs. How do you solve problems caused by BFCs?

## HTML

- Are you familiar with PWA specifications?
- Briefly explain custom elements (even better if you discuss them alongside Web Components)
- Briefly explain replaced elements

## Browsers and Engineering Practices

- What does HTTP2 bring to frontend development?
- How would you architect a new frontend project?
- How do browsers optimize reflow and repaint?
- How can browser tabs communicate with one another?
- What causes cross-origin issues? (This probably won't be asked anymore.)
- Have you developed any browser extensions?
- Are you familiar with micro-frontends?
- Are you familiar with serverless?
