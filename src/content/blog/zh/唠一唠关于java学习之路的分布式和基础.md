一个前端 Vue 项目结束了，也上线了，对自己提升很大。今天和导师聊天，聊到了工作。

背景：大专学历，两年学习经历。两位朋友经导师推荐去朋友的小厂面试——需要两个"码农"，几个月做个后端管理系统，对技术要求不高（SSM 会做增删改查就行）。但据说面试了一个月的应届生和培训出来的，没一个能写出增删改查。

朋友有机会去磨练，我也就跟着去了。结果三小时之内，第二小时就被委婉劝走了。原因我觉得有几个：

1. 紧张，第一次这种环境下的机试
据我所知，这两位朋友代码功底挺深的，不谈什么高大上的分布式、线程、熔断这些乱七八糟的技术，光增删改查玩得还是很 6 的。
2. 过于相信自己的技术
我们学校尤其是我们班都是以实战为主，两年不知道做过多少 demo 和项目练习。对自己的技术过于自信，没有认真准备，轻视了这次机会。我相信他们一定会引以为戒。

**基础重要还是高大上的技术重要？**

我的理解：深入 Java 基础很重要，高大上的技术是通过第三方渠道了解的——别人教的、视频学的、工作接触的。

所以即将春招的应届毕业生，不要追求很多新潮的技术，也不要忘了基础。不要轻信任何一个 demo 或者练习。
